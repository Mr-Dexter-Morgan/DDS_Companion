DDS Companion 0.5.5 — короткий Windows live-check

1. Библиотека: кликнуть канал, затем поводить мышью по другим строкам. Правая панель НЕ должна переключаться без клика.
2. Кликнуть несколько обычных каналов и тем. Сообщения должны появляться именно у выбранного узла. Если у родительского канала нет прямых сообщений, но есть темы, интерфейс должен это объяснить.
3. Проверить колонку «Выгрузка»: комбобокс читается, колонку можно растянуть.
4. Открыть «Статус»: сверху должны быть вкладки «Статус» и «Жизненный цикл медиа».
5. Во вкладке «Жизненный цикл медиа» проверить счётчики: Всего / Известно / Кэшировано / Требует внимания / Обработано / Ждёт переобнаружения.
6. При большом списке проблем нажать «Игнорировать всё». Все текущие terminal/stale проблемы должны перейти в «Обработано» без ручного прокликивания строк.
7. Нажать «Очистить обработанные». Обработанные строки должны исчезнуть из списка и перейти в «Ждёт переобнаружения»; повторной мясорубки по старым URL быть не должно.
8. После получения свежей ссылки Discord для такого вложения оно должно снова стать «Известно» и при включённой автозагрузке снова иметь возможность закэшироваться.
9. Главная: карточка медиа должна показывать понятные подписи вместо формата «186 / 85».
10. Короткий smoke: импорт/Watcher/Plugin остаются RUNNING, архив сообщений не повреждён, правила будущей выгрузки сохраняются после перезапуска.
