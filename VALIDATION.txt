candidate-r2 delta validation
- Live finding from Windows: the r1 default used C:\Users\<user>\Documents\DDS Exports even when Documents had been relocated by Windows to another drive.
- Root cause: default_manual_export_path() used Path.home() / "Documents" instead of the Windows Known Folder API.
- Fix: installed profile now resolves FOLDERID_Documents via SHGetKnownFolderPath; fallback remains non-fatal.
