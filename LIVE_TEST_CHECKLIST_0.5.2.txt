DDS Companion 0.5.2 — Windows Live Test Checklist
=================================================
Status before live pass: CANDIDATE / 81/81 AUTOMATED PASS

This is a bounded regression gate, not another full 0.5.0 media campaign.

1. STARTUP / MIGRATION SAFETY
[ ] Start 0.5.2 on the existing data root used by 0.5.1.
[ ] Message/server/media counts remain present; no archive loss.
[ ] Overall archive/capture remains RUNNING unless a real critical subsystem is unavailable.

2. EXISTING LIVE FAILURE SURFACE
[ ] Open Статус.
[ ] Existing failed attachment appears in «Медиафайлы, требующие внимания».
[ ] Summary says «1 медиафайл требует внимания» when exactly one unresolved item exists.
[ ] Filename + human reason + state are readable.

3. DETAILS
[ ] Select the item and press «Подробнее».
[ ] Dialog shows expected size / attempts / HTTP / technical cause / last error / media key.
[ ] No crash or UI freeze.

4. RETRY
[ ] Press «Повторить».
[ ] Exactly the selected item is re-armed; unrelated cached media is not redownloaded.
[ ] A repeated complete size mismatch returns to an actionable terminal state without five identical downloads.

5. IGNORE / RECOVERY SEMANTICS
[ ] Press «Игнорировать» and confirm.
[ ] Item remains listed as «Игнорируется».
[ ] It no longer counts as «требует внимания».
[ ] If it was the only unresolved media issue, Media Backfill no longer remains LIMITED solely because of it.
[ ] Archive/SQLite/message counts are unchanged.

6. RESTART
[ ] Close normally and relaunch.
[ ] Ignored acknowledgement persists.
[ ] Selecting ignored item and pressing «Повторить» remains possible.

7. LIBRARY PATH / TRUTHFUL WORDING / SHUTDOWN
[ ] Библиотека no longer shows «Открыть папку библиотеки».
[ ] Technical folder access is still available in Настройки -> Хранилище -> Расположение файлов.
[ ] Bottom bar says «ошибок импорта: N», not generic unresolved failures.
[ ] Critical error card does not contradict the separate media issue block.
[ ] Normal close produces no traceback and background runtime stops cleanly.
