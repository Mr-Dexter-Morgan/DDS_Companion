DDS Companion 0.5.6 — короткий Windows live-check

1. «Жизненный цикл медиа»: создать/оставить длинный список файлов «Требует внимания», прокрутить почти в самый низ и подождать 10–20 секунд. Автообновления НЕ должны возвращать таблицу наверх и не должны сбрасывать выбранную строку.
2. Библиотека: в колонке «Медиа: известно / всего» проверить сервер, канал и тему. Цифры должны соответствовать состояниям из «Жизненного цикла медиа» именно для этой ветки; unresolved/attention должны быть видны отдельно.
3. Библиотека: открыть сообщения с `*курсивом*`, `**жирным**`, `~~зачёркнутым~~` и `code`. Сырые маркеры Markdown не должны торчать как обычный текст.
4. Библиотека: проверить колонку «Выгрузка». Текст комбобокса не должен быть обрезан сверху/снизу. Провести мышью по соседним каналам — preview не должен переключаться без клика.
5. Пока Библиотека открыта, дождаться фонового обновления структуры/медиа-счётчиков. Позиция дерева не должна прыгать наверх.
6. «Активность»: пользовательские строки должны быть на русском/человеческом языке. `media_processed_cleared`, `health_reason_changed`, `startup_sync` и подобные ID не должны торчать в таблице как основной текст; технический ID допустим только в tooltip.
7. Проверка heartbeat-spam: при остановленном/протухшем heartbeat возраст может расти, но новые одинаковые `health_reason_changed` каждые 2–3 секунды появляться не должны.
8. «Статус»: карточки База данных / Импорт / Наблюдение / Загрузка медиа / Обновления и временные подписи должны быть русифицированы; RUNNING/LIMITED остаются системными состояниями.
9. Регрессия 0.5.5: Ignore All -> Clear Processed должен переводить обработанные записи в «Ждёт переобнаружения», не запускать старые URL по кругу и позволять свежему capture вернуть объект в Known.
10. Smoke: импорт/Watcher/Plugin работают как раньше, архив и media registry не повреждены, правила будущей выгрузки сохраняются после перезапуска.
