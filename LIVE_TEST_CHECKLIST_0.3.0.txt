DDS Companion 0.3.0 — Live Windows Test Checklist

1. Keep DDS Plugin 0.5.2 enabled.
2. Extract DDS_Companion_0.3.0.zip to a new folder.
3. Do NOT delete %LOCALAPPDATA%\DDS_Companion\database\dds.sqlite3.
4. Run run_companion.bat.
5. Confirm startup contains:
   DDS Companion v0.3.0 [RUNNING]
   Health : DB=RUNNING | DDS=RUNNING | Importer=RUNNING | Watcher=RUNNING
6. Confirm archive totals are preserved from 0.2.0 and unchanged captures are skipped.
7. Open/scroll one Discord channel or thread so DDS changes capture.json.
8. Confirm:
   WATCH changed/new capture ... (settling)
   ACTIVITY +N messages imported, M existing refreshed ...
9. Leave it running long enough for normal watcher activity; confirm no crash.
10. Press Ctrl+C and confirm clean shutdown / watcher summary.

Do NOT intentionally corrupt the real DDS_Data. Malformed-capture recovery is already automated-tested.

Pass gate for VERIFIED:
- existing archive preserved
- schema migration completes automatically
- all startup health subsystems RUNNING
- live Activity event appears after a real DDS capture change
- clean Ctrl+C shutdown
