DDS Companion 0.4.3 — Windows Live Test Checklist
==================================================

1. Start with run_companion.bat.
   [ ] GUI opens without a persistent console.
   [ ] Window title shows DDS Companion 0.4.3.
   [ ] Sidebar brand shows the full text "DDS Companion" at 1366x768.

2. Open Health.
   [ ] Page renders and scrolls cleanly if needed.

       Update check.

   [ ] Last error says "Ошибок нет" when no unresolved failure exists.

3. Discord informational probe.
   [ ] With Discord running, Discord card becomes RUNNING within ~5 seconds.
   [ ] Close Discord; card becomes NOT RUNNING within ~5 seconds.

   [ ] Reopen Discord; card returns to RUNNING.

4. Update telemetry surface.
   [ ] With no updater configured yet, state is NEVER.
   [ ] Interval shows 6 h.
   [ ] Last attempt and Next are shown as — rather than fabricated timestamps.
   [ ] No GitHub/network error is shown merely because updater is not implemented.

5. Regression smoke test.
   [ ] Dashboard renders/scrolls normally.
   [ ] Library renders archive tree.
   [ ] Activity renders event history.
   [ ] Settings still opens on Основные and Paths & Storage still works.
   [ ] New Discord messages continue importing automatically.
   [ ] Closing the window stops the session cleanly.
