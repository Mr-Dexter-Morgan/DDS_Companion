Archive reset
-------------
- Added a separate destructive action: «Сбросить локальный архив».
- Cache clear and archive reset are now explicitly different operations.
- Full reset removes SQLite + WAL/SHM sidecars and local media cache while preserving settings.
- Reset stops the runtime first, waits for SQLite/watcher/media workers to release files, recreates a clean current-schema DB, then restarts the runtime.
- Added a reset-boundary marker outside SQLite so pre-reset DDS_Data captures are NOT immediately re-imported after a clean-slate reset.
- When Plugin later rewrites/touches a capture after the boundary, it becomes eligible for import again.

Expired Discord media URLs
--------------------------
- HTTP 401/403/404 from Discord media are now treated as expired-link rediscovery, not as a fake manual decision.
- Confirmed expired links move directly to UNRESOLVED / «ожидает переобнаружения».
- Dead signed URLs are cleared from the active row so the downloader cannot loop on the same URL.
- Expired-link rows no longer appear in the normal action-required issue queue.
- Legacy STALE_URL / stale-url IGNORED rows are normalized to the passive rediscovery state at media-runtime startup.
- Fresh Plugin observation of the same stable attachment can promote it back to KNOWN and then CACHED.
- Retry remains available for genuinely transient failures such as network errors / temporary server failures.
- Diagnostics snapshot keeps passive rediscovery items with filename, state, HTTP status, failure class, timestamp, media key and last error.

UI / product polish
-------------------
- Removed the secondary «Companion» label from sidebar branding; public identity is DDS — Discord Data Snatcher.
- Qt application display name is now DDS, while the explicit main-window title remains the full product name + version. This avoids the duplicate Windows title observed in the 0.6.0 live build.
- Public GUI dialog titles use DDS rather than competing DDS Companion branding.
- Storage session delta is now semantic:
  - decrease -> «Освобождено за сессию: …»
  - increase -> «Добавлено за сессию: …»
  - tiny/no change -> «Без изменений за сессию».

Safety / regression hardening
-----------------------------
- Runtime/media UI actions tolerate the runtime being temporarily unavailable during archive reset/restart.
- Installed DataRoot, Portable foundation, approved DDS icon, DDS.exe identity, archive schema and existing Library/Activity/Status/Diagnostics contracts remain unchanged.
