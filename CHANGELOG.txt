DDS Companion 0.5.2 — Media Attention Recovery
================================================
Date: 2026-09-18
Status: CANDIDATE / 80/80 AUTOMATED PASS / WINDOWS LIVE PENDING
Baseline: 0.5.0 — VERIFIED / LIVE TESTED / CURRENT RECOMMENDED
Supersedes before promotion: 0.5.1 candidate

LIVE FINDING CLOSED
- A real attachment advertised 1,304,279 bytes but repeatedly returned a complete 329,666-byte payload.
- 0.5.1 eventually marked the object FAILED_PERMANENT and left Media Backfill LIMITED with no normal user action.
- Archive/capture remained healthy; defect classified as media recovery/usability, not archive integrity.

MEDIA ATTENTION UX
- Added Status block «Медиафайлы, требующие внимания».
- Shows filename, human reason and state.
- Added actions: «Повторить», «Игнорировать», «Подробнее».
- Human count wording includes «1 медиафайл требует внимания».
- Ignored items stay visible and are reversible through Retry.

RECOVERY SEMANTICS
- Added durable media lifecycle state IGNORED.
- Ignore removes the item from unresolved Media Backfill attention without deleting archive metadata.
- Signed-URL rotation does not silently undo an explicit Ignore.
- Explicit Retry targets one media key and performs one attempt even when automatic media download is Off.

SIZE-MISMATCH HARDENING
- Transport records HTTP Content-Length when available.
- A fully received payload whose Content-Length equals received bytes but differs from Discord metadata is classified as metadata_size_mismatch after one attempt.
- DDS does not cache that mismatched binary automatically.
- Incomplete/truncated responses remain retryable.

LIBRARY PATH USABILITY
- Removed misleading «Открыть папку библиотеки» from Библиотека; it opened the technical app-data root.
- Technical path access remains in Настройки -> Хранилище -> Расположение файлов.
- Broader Library tree/details redesign remains separate pending finalized UX.

TRUTHFUL STATUS
- Bottom status now says «ошибок импорта» rather than ambiguous unresolved failures.
- «Последняя ошибка» became «Последняя критическая ошибка»; per-file media problems are shown separately.
- Media failures remain isolated: Overall archive/capture can stay RUNNING while Media Backfill needs attention.

AUTOMATED VALIDATION
- 81/81 PASS repeated three consecutive runs.
- compileall PASS.
- CLI version PASS: DDS Companion 0.5.2.

WINDOWS LIVE GATE
- Short bounded verification remains required before promotion.
