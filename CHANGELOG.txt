DDS Companion 0.4.3 — Health Telemetry Patch
=============================================

Status: BUILT / LOCAL TESTING

Purpose
-------
Make the Health page describe the real runtime state more accurately while
preserving the stable archive/import/watch pipeline and the accepted 0.4.2 UI.

Changed
-------
- Fixed compact-layout brand truncation: DDS Companion now has enough sidebar
  width at the 1366x768 compact profile.
- Health page is scroll-safe and adds Discord + Update check cards.
- Database and DDS_Data cards are live probes on every Health snapshot.
- Watcher heartbeat expiry is surfaced as STALE instead of being folded into a
  generic DEGRADED label.
- Discord stable / Canary / PTB process detection added on Windows using the
  built-in tasklist command; no new dependency.
- Discord NOT RUNNING is informational and does not affect overall archive
  health.
- Update telemetry surface added with a 6-hour default interval. 0.4.3 does not
  contact GitHub; it only displays scheduler state when it exists.
- Last unresolved error now includes subsystem/job kind and occurrence time and
  disappears after the durable failed job is resolved.

Unchanged
---------
- Archive schema and accumulated data.
- Import/dedup/watcher semantics.
- Dashboard, Library, Activity and Settings IA.
- No media downloading or cloud synchronization.

Validation
----------
- Python compileall: PASS.
- Full automated suite: 35/35 PASS.
- 0.4.2 regression behavior retained.
