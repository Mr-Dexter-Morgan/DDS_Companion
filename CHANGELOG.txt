DDS Companion 0.4.2 — Settings Information Architecture
========================================================

Status: BUILT / LOCAL TESTING

Purpose
-------
0.4.2 is a focused UI patch over the live-tested 0.4.1 GUI. It separates
important Companion settings from low-priority filesystem paths so the Settings
page can grow without being dominated by storage locations.

Changed
-------
- Settings now has two internal tabs:
  - Основные — default tab for user-facing and runtime settings.
  - Paths & Storage — service paths and one-click folder access.
- Watcher policy moved to the default Основные tab.
- All path rows (Library, DDS_Data, SQLite, logs, media, cache, backups) moved to
  the dedicated Paths & Storage tab.
- Added dedicated tab styling consistent with the existing dark UI.
- Paths & Storage remains independently scrollable on constrained displays.
- No fake editable controls were introduced; settings remain read-only until
  persistence/validation exists for each option.

Unchanged
---------
- Archive schema, importer, watcher and observability behavior.
- Dashboard, Library, Activity and Health behavior.
- Normal pythonw launcher and responsive layout profiles from 0.4.1.

Validation
----------
- Python compileall: PASS.
- Full automated suite: 28/28 PASS.
- Previous 27 tests remain PASS.
- Added Settings tab/source contract test: PASS.

Live-test boundary
------------------
