DDS Companion 0.5.7 — Final BAT-era Library / Diagnostics polish

- Библиотека: убрана визуальная hover-подсветка, которая выглядела как настоящий выбор строки после возврата курсора из правой панели. Выбранной остаётся только строка, по которой пользователь реально щёлкнул.
- Библиотека: горизонтальная прокрутка дерева отключена, чтобы заголовок/первый столбец не приезжали обратно со старым offset и не обрезались слева.
- Библиотека: пользовательская «Выгрузка» упрощена до двух вариантов — «Не выгружать» и «Выгружать». Внутренний legacy DEFAULT остаётся совместимым с существующей БД, но в UI больше не показывается; отсутствие явного корневого правила по-прежнему безопасно означает «не выгружать».
- Библиотека: колонка «Выгрузка» сделана фиксированной и компактной, чтобы комбобоксы не меняли геометрию дерева при обновлениях.
- Библиотека: перед Qt Markdown нормализуются Discord custom emoji (`<:name:id>` / `<a:name:id>`) в читаемое `:name:`; object-replacement glyph заменяется на обычный маркер. Это уменьшает вероятность пустых квадратов в старых сообщениях.
- Активность: колонка «Событие» расширена, чтобы русские человекочитаемые названия меньше обрезались.
- Диагностика: пользовательские подсказки дочищены от смешения русского и служебного английского (`unresolved failures`, `read connection`, `diagnostics report`).
- Диагностика: контракт захвата теперь показывает реальный поддерживаемый Companion capture schema v2 и heartbeat contract `plugin-heartbeat-v1`, вместо пустого `capture —`.
- Capture schema v2 вынесена в общий контрактный constant, которым пользуются и validator, и Health/Diagnostics; логика проверки capture не менялась.
- Media Lifecycle, branch-level media counters, scroll preservation, heartbeat event dedup и Ignore All -> Clear Processed -> UNRESOLVED -> rediscovery не менялись после успешной live-проверки 0.5.6.
- BAT/pythonw taskbar identity / foreground quirks намеренно не маскируются новыми костылями в этом патче: это переносится в следующий архитектурный этап 0.6.0 с нормальным Windows EXE.

Реальная выгрузка архива на Google Drive по правилам выбора по-прежнему не включена в этот патч.
