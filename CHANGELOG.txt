Dashboard
---------
- Removed duplicated subsystem Health card.
- Removed Open DDS_Data / Open logs maintenance shortcuts.
- Added storage donut/ring and percentage + size breakdown.
- Global top Health pill is now a Health-page shortcut outside Health itself.

Settings / Storage
------------------
- Rebuilt Settings into General / Data & Storage / Archive / Diagnostics.
- Added atomic persistent settings store under Companion config.
- Added real media-cache policy controls: cache size limit, max file size, retention age, clear-confirmation.
- Added media cache policy engine with oldest-first limit eviction.
- Retention currently uses file mtime until Media Backfill adds explicit last-access tracking.
- Manual Clear media cache deletes binary cache files only.
- Clear button is disabled when cache size is 0 B.

Diagnostics
-----------
- Moved logs/data maintenance access out of Dashboard.
- Added System report generation and Copy report.
- Added SQLite PRAGMA quick_check using a separate read connection.

First-run source bootstrap
--------------------------
- PySide6 is treated as a required GUI component.
- Missing PySide6 is installed automatically without a Y/N prompt.
- Successful bootstrap verifies the import and launches the GUI.
- Failure leaves archive data untouched and keeps a readable diagnostic console open.
