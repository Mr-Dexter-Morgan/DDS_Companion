DDS Companion
Version: 0.3.0
Date: 2026-09-13
Authors: Mr_Dexter_Morgan, Masya

Activity & Health Core release.

Changes since 0.2.0:
- Added durable ActivityService backed by SQLite activity_events.
- Added in-memory Activity subscriptions for CLI now and GUI later.
- Subscriber exceptions are isolated and cannot terminate archive processing.
- Added human import Activity with capture path, Discord context and import counters.
- Added persisted session lifecycle Activity.
- Added HealthService with subsystem_health table.
- Added subsystem states: STARTING, RUNNING, DEGRADED, ERROR, STOPPED, UNKNOWN.
- Added database, DDS_Data, importer and watcher subsystem health.
- Added persisted watcher heartbeat and stale-heartbeat detection.
- Importer health remains DEGRADED while unresolved failures remain.
- Added StatsService snapshot API with process-session baseline.
- Added session messages/imports/activity/storage deltas.
- Added known-media vs cached-media counters.
- SQLite storage accounting now includes main DB + WAL + SHM.
- Added cache/media/log storage accounting.
- Added RuntimeMonitor bridge from watcher facts to Activity + Health.
- Watcher now exposes isolated state and heartbeat callbacks.
- Console startup now exposes Health, Session and Activity rows.
- Live imports are presented as durable ACTIVITY events rather than only low-level watcher output.
- Added OBSERVABILITY_CONTRACT.md for the future 0.4.0 GUI model boundary.

Database:
- Schema version 1 -> 2.
- Adds activity_events.
- Adds subsystem_health.
- Existing archive tables are preserved in place.
