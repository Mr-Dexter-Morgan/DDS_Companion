DDS Companion 0.4.0 — Desktop Dashboard
========================================

Status: BUILT / LOCAL TESTING

Added
-----
- First PySide6 desktop interface.
- Dark graphite + restrained blue/violet visual system.
- Dashboard / Library / Activity / Health / Settings navigation.
- Live Dashboard bound to Stats/Health/Activity snapshots.
- Total storage, session delta, messages, contexts and media counters.
- Storage breakdown including SQLite family, DDS JSON, cache, media and logs.
- LibraryService read-only Server → Channel → Thread hierarchy.
- Activity table from persisted activity_events.
- Health page for Database / DDS_Data / Importer / Watcher.
- One-click Open library folder / Open DDS_Data / Open logs actions.
- Settings path cards for database/cache/media/backups/logs.
- Runtime-generated DDS icon.
- GUI dependency bootstrap and PySide6 installer helper.
- Separate run_cli.bat preserving the proven headless watcher.

Architecture
------------
- Added dds_companion.gui.runtime.GuiRuntime.
- SQLite remains confined to one background runtime thread.
- Qt receives snapshots through signal callbacks, not direct SQL calls.
- Added optional CaptureWatcher.on_tick callback; observer exceptions are isolated.
- Added LibraryService so Qt does not depend on the archive schema.
- Manual UI refresh uses a thread-safe Event.

Validation
----------
- 21/21 automated tests PASS.
- All 18 previous regression tests remain PASS.
- Library hierarchy test PASS.
- GUI runtime start/snapshot/clean-stop test PASS.
- Live capture change through watcher/importer/activity test PASS.
- Python compileall PASS.

Known validation gap
--------------------
- The build environment does not have PySide6 installed, so native Qt rendering
  has not been visually executed here.
- The release must remain BUILT / LOCAL TESTING until the real Windows machine
  confirms window rendering, navigation, quick folder actions and live UI update.
