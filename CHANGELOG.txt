DDS Companion 0.4.1 — GUI Polish / Responsive Layout
=====================================================

Status: BUILT / LOCAL TESTING

Purpose
-------
0.4.1 is a focused polish release over the live-tested 0.4.0 desktop GUI.
It does not change the archive schema, importer contract or watcher behavior.

Changed
-------
- Dashboard is now scroll-safe instead of relying on a fixed-height layout.
- Added Compact / Standard / Large layout profiles selected from usable screen
  geometry, logical DPI, device-pixel ratio and current window width.
- Compact mode rearranges metric cards into a 2x2 grid and stacks lower
  dashboard panels vertically, preventing the 1366x768 storage panel overlap.
- Standard/Large modes preserve the wider desktop card layout.
- Window initial size now respects available screen geometry instead of always
  requesting 1320x840.
- Layout profile is re-evaluated on window resize, screen changes, available
  geometry changes and logical-DPI changes.
- Sidebar navigation now has clearly different idle, hover and selected states.
- Removed duplicate Open Library actions from the top bar and Dashboard.
  Library page is now the single Open library folder location.
- Refresh is now a compact secondary action rather than plain ghost text.
- Normal launcher hands the GUI to pythonw.exe/run_companion.pyw so a console
  is not kept open during normal use.
- Added run_companion_debug.bat for an intentional console/debug session.

Unchanged
---------
- Accumulating SQLite archive behavior.
- Watcher settle/retry/isolation semantics.
- Activity / Health / Stats services.
- Library Server → Channel → Thread model.
- DDS_Data source contract.
- No media download, search, Drive sync, tray, autostart or installer yet.

Validation
----------
- Python compileall: PASS.
- Full automated suite: 27/27 PASS.
- Previous 21 tests remain PASS.
- Added 3 layout-profile tests for 1366x768, 1080p and dense 4K cases.
- Added 3 source-contract tests for scroll safety, launcher split and duplicate
  Open Library action removal.

------------------
