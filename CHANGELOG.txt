DDS Companion 0.5.3 — Library UX
================================

- Reworked Library into a two-pane archive browser.
- Kept natural Discord hierarchy: server -> channel -> thread.
- Replaced developer-facing ID column with human columns: Раздел / Сообщений / Медиа.
- Added details panel: type, archive location, message count, media count, last activity and technical ID.
- Added explicit Copy ID action in details instead of exposing IDs in the main tree.
- Updated Library search wording and removed ID-based filtering from the ordinary search field.
- Extended LibraryService snapshots with media counts and last-activity timestamps.
- Preserved selection/expansion across refresh and auto-selects the first server when available.
- No SQLite schema, Watcher, importer or Media Runtime redesign.
